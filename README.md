# Bare Metal Gaming – website redesign

A static mock-up of a refreshed homepage for baremetalgaming.com.

Open `index.html` in a browser, or view it via GitHub Pages if enabled.

- `index.html` – page content
- `styles.css` – styling
- `script.js` – plan data, price/tier switches, Managed Service price

Notes: the Managed Service fee (£10 / €12) is a placeholder, and the advice form is not connected to a backend yet.
