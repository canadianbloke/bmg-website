05 / FAQ

How the platform works

How do the included server slots work?

Each plan includes a number of server slots: 3 on Ingot, 6 on Anvil, 12 on Crucible and 24 on Forge. That's how many game servers you can have installed in AMP at once. Run one heavy server or several light ones at the same time; the only limit is your CPU and RAM. Extra slots are £1 / €1 per month.

Can we switch games when the group moves on?

Yes. In your AMP portal you can stop a server, back it up or delete it, and deploy a different supported game in minutes at no extra cost.

What's the difference between Aluminium, Steel and Titanium?

Same RAM and cores within a series. Aluminium uses HDD storage in Germany. Steel uses SSD and unlocks global locations. Titanium uses NVMe, global locations and dedicated vCPU cores for guaranteed tick rates.

How is this different from slot-based game hosts?

Slot hosts put your game on a crowded machine shared with strangers. With Bare Metal Gaming you get an isolated vPC with dedicated RAM, 16 GB of pre-configured swap for memory spikes, automated backups and a monthly security patch cycle.

Why no weekend rentals?

Every environment is provisioned by hand, security-hardened and given its own AMP instance. That engineering time goes into a stable long-term hub, so the platform is designed for ongoing groups.

What is AMP, and which games can I host?

CubeCoders AMP is the control panel you use to deploy and manage servers. It supports a large library of survival, RPG, FPS and other multiplayer titles. See the full live list on the CubeCoders AMP compatibility page.

What does the Managed Service add-on cover?

We handle the day-to-day running of your server: game and mod updates, installing new games and modpacks, performance tuning, fixing crashes and restoring backups, with priority support. You still have full access to your AMP panel, and you can drop the add-on at any time without losing your server.
